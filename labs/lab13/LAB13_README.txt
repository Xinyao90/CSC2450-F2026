CSC-2450 Lab 13 — Development Environment and vi/Vim

Work only inside your own lab13 directory. Do not use sudo.

Suggested setup:
  mkdir -p ~/csc2450-work/labs/lab13
  cp ~/CSC2450-F2026/labs/lab13/* ~/csc2450-work/labs/lab13/
  cd ~/csc2450-work/labs/lab13
  pwd
  ls -l

Core tasks:
1. Practice opening and exiting vi safely.
2. Edit server_notes.txt using Insert and Normal modes.
3. Navigate using hjkl, w, b, 0, $, gg, G, and a count.
4. Practice undo, delete, yank, paste, append, and open-line commands.
5. Search service_log.txt and create service_log_reviewed.txt with a confirmed substitution.
6. Optional challenge: repair broken_fizzbuzz.py and run it with python3.

Keep the original supplied files. Use :w new_name to save edited copies when instructed.
